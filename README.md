# Nas Amar

**AI systems engineer · Technical consultant · Founder**

I work across AI, operating systems, search, graphics, and human interfaces. I like understanding systems deeply enough to make powerful technology feel natural to the people using it.

I founded **Poez Inc.** and co-founded **GoAIX**. Previously, I was a Principal Software Engineer at Microsoft, where I worked on Windows Shell, Search, AI, and hardware experiences reaching more than a billion customers.
